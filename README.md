# Карманный блокнот
Мобильный блокнот без сервера, зависимостей и аналитики. Вставьте текст, задайте название и нажмите «Сохранить .txt». UTF-8, исходные переносы строк, без добавленного BOM. Черновик в IndexedDB. Несколько вкладок используют один черновик: последняя запись побеждает. Важный текст скачивайте, браузер может удалить свои данные.

## GitHub Pages
Создать публичный репозиторий `pocket-notepad`, загрузить index.html, sw.js, manifest.webmanifest, оба PNG и .nojekyll в корень ветки main. Settings → Pages → Deploy from a branch → main → / (root) → Save. Адрес: https://tmksdm.github.io/pocket-notepad/ (станет доступен после публикации).

Для локального HTML откройте index.html в браузере: TXT работает, PWA требует HTTPS. Встроенный просмотрщик файлов телефона может не исполнять JavaScript.

## Проверка
`python3 -m http.server 8765` из папки проекта, затем `node tests.cjs` (нужен Playwright с Chromium).

Разделители U+2029 автоматически заменяются на пустую строку между абзацами, U+2028 и U+0085 — на перенос строки. Нормализация выполняется при вводе/вставке, восстановлении черновика и выгрузке TXT. Обычные переносы и видимые символы квадратов сохраняются.
